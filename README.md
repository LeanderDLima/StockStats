#StockStats

Built to cut through market noise. StockStats focuses on what’s controllable: live data, baseline risk metrics (Sharpe ratios), and automated AI workflows with minimal overhead.

In summary, It is a Python financial terminal built with CustomTkinter and the Gemini API. It tracks live market data, computes risk metrics, and uses AI batch processing to filter financial news headlines.

## Features
- Real-time market data tracking via yfinance
- Quantitative risk metrics and volatility analysis
- AI-driven news filtering using Gemini 3.6-flash
- Minimalist OLED dark-mode desktop interface
