#StockStats 2026

StockStats is a Python financial terminal built with CustomTkinter and the Gemini API. It tracks live market data, computes risk metrics, and uses AI batch processing to filter financial news headlines.

## Features
- Real-time market data tracking via yfinance
- Quantitative risk metrics and volatility analysis
- AI-driven news filtering using Gemini 3.6-flash
- Minimalist OLED dark-mode desktop interface

## Setup
1. Install dependencies:
   pip install -r requirements.txt
